🛒 Noor Super Store POS

Noor Super Store POS is a modern, professional, and responsive Point of Sale (POS) system designed for small businesses and retail stores.

Built entirely with HTML, CSS, and JavaScript, the project works as a single-file application and stores data locally using Browser LocalStorage.

✨ Features

- 🔐 Professional POS Login
- 📊 Dashboard & Business Overview
- 🛒 Point of Sale / Shopping Cart
- 📦 Product & Inventory Management
- 🔎 SKU / Barcode Search
- 📷 Barcode Scanner Support
- 👥 Customer Management
- 💳 Cash, Card, Bank & Credit Payments
- 💰 Discount & Tax Calculation
- ⏸️ Hold & Resume Carts
- 🧾 Professional Printable Receipts
- 🔄 Reprint Previous Receipts
- 💸 Expense Management
- 📈 Sales & Profit Reports
- 🏆 Best-Selling Products
- ⚠️ Low-Stock Alerts
- 📒 Customer Credit & Payment Tracking
- 💾 JSON Backup & Restore
- 🎨 Multiple Color Themes
- 🌙 Dark Mode
- 📱 Mobile Responsive Design
- 🇵🇰 Pakistani Rupees (PKR/Rs)
- 💿 LocalStorage Data Persistence

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
- Google Fonts

📱 Usage

No database or backend server is required. Simply open the HTML file in a modern web browser and start using the POS system.

For regular data protection, use the Export Backup option in Settings.

⚠️ Disclaimer

This project is intended for personal, educational, and small-business use. Always maintain regular backups of important business data.
